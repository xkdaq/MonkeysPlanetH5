## 2026-08-21 转盘扇区题号显示修复

问题：用户截图中 49 题转盘扇区只显示彩色块，没有"第 x 题"文字。
原因：`drawWheel` 里 `const showLabel = N <= 40;`，超过 40 题就不画文字。
修复：阈值放宽到 `N <= 80`，并动态缩小字号（N>60 用 9px，N>40 用 10px，N>30 用 11px，否则 13px），文字位置内移到 `R - 16`。已重新 build，本地实测 49 题、63 题扇区文字均显示。

## 2026-08-21 题库选择器改为下拉框

需求：题库数量会越来越多，横向 chips 占空间且不便扩展。
改造：`public/html/333/大转盘.html` 的 `#bankSelect` 从横向 chips 改为 `<select>` 下拉选择框：
- 圆角药丸样式，深色背景，右侧自定义下拉箭头；
- focus 边框跟随当前题库主题色（通过 CSS 变量 `--bank-color` 动态设置）；
- option 深色背景，适配暗黑主题；
- 保留 localStorage 记住上次选择的题库。
已重新 build，本地验证下拉框渲染正常。
